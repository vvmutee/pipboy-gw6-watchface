# Как установить на часы

Нужны компьютер с Windows или macOS, актуальная Samsung Watch Face Studio и часы на Wear OS 5+. На Galaxy Watch6 с Wear OS6 установка и основные показатели проверены автором.

## 1. Скачай и открой проект

1. Скачай [PipBoy_GW6.wfs](https://github.com/vvmutee/pipboy-gw6-watchface/raw/refs/heads/main/PipBoy_GW6.wfs). Если открылась страница файла, нажми Download raw file.
2. Установи [Samsung Watch Face Studio](https://developer.samsung.com/watch-face-studio/download.html).
3. В WFS выбери File → Open Project и открой скачанный `.wfs`.
4. Сохрани собственную копию. Превью в Studio показывает тестовые показатели.

## 2. Подготовь часы

1. Подключи часы и компьютер к одной Wi-Fi-сети.
2. На часах: Настройки → О часах → Сведения о ПО. Нажми «Версия ПО» несколько раз до включения режима разработчика; на Galaxy Watch обычно пять раз.
3. Вернись в Настройки → Параметры разработчика.
4. Включи Отладка ADB и Беспроводная отладка. Разреши использование текущей сети, если часы спрашивают.
5. На основном экране беспроводной отладки запиши IP-адрес и порт подключения.
6. Открой «Подключить новое устройство / Pair new device». Появятся шестизначный код и отдельный порт сопряжения. Этот экран держи открытым при сопряжении.

## 3. Установи через WFS

1. Нажми Run on Device → +.
2. Заполни поля данными со своих часов:

| Поле | Что вводить |
|---|---|
| IP Address | IP часов без двоеточия и порта |
| IP Port | Порт с основного экрана беспроводной отладки |
| Pairing Port | Порт с экрана Pair new device |
| Pairing Code | Свежий шестизначный код с этого же экрана |

3. Нажми OK. Подтверди запрос отладки на часах, если появится.
4. В списке Connected Devices нажми на свои часы и дождись сборки и установки.
5. При запросе данных подписи создай свой ключ через диалог WFS. Файл ключа и пароль храни отдельно; не добавляй их в GitHub.

**Не путай два порта.** Код и порт сопряжения могут измениться при повторном открытии Pair new device. При ошибке проверь свежие значения, доступ устройств в одной сети и разрешение отладки.

## 4. Данные и AOD

- Разреши доступ к показателям здоровья, если часы его запросят. Для проверки пульса надень и разблокируй часы, получи измерение в Samsung Health и вернись к циферблату.
- Открой Погоду на часах, настрой местоположение и дождись актуальных данных. При отсутствии данных циферблат показывает `--°C`. Отдельно назначать погодное усложнение в этой версии не нужно.
- Сверь HP с зарядом часов. Пройди несколько шагов и проверь AP. Цель шкалы AP можно менять в Settings → Health проекта WFS.
- Включи Always On Display в настройках экрана часов. В AOD должны остаться только часы и минуты на чёрном фоне.
- После установки отключи беспроводную отладку. Если Bluetooth временно отключался, включи его снова.

При обновлении используй тот же собственный ключ подписи. Другие модели и версии Wear OS могут требовать отдельной проверки.

Официальные инструкции: [подключение Samsung по Wi-Fi](https://developer.samsung.com/sdp/blog/en/2023/11/14/connecting-galaxy-watch-to-watch-face-studio-over-wi-fi), [погодные данные WFS](https://developer.samsung.com/codelab/watch-face-studio/weather-data.html).
